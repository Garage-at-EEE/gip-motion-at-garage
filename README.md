# gip-motion-at-garage
Garage’s Branding &amp; Marketing team regularly works with video, product photography and other visual content. Motion@Garage aims to create an in-house platform that makes repeatable, programmable camera movements possible.
The system will combine a motorised camera slider with additional movement modules such as pan control or a product turntable. Beyond the tool itself, the project develops technical fabrication capability within BnM so members can build, maintain and extend their own production equipment.
